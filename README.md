# Matty H Cards · The Collection

Public gallery of the Matty H Cards collection. Live at https://mattyhcards.github.io

- `data/cards.json`: public card data only (no costs, platforms or notes), built by `tools/build_data.py` from the tracker.
- `img/cards/<Card ID>/`: 4:5 web photos (`front.jpg`, `front-thumb.jpg`, later `back.jpg`), made by `tools/prep_photos.py`.
- `assets/icons/`: SSP, Rookie Card and MHC Top 100 icons. Swap these SVGs to restyle the icons site-wide.
